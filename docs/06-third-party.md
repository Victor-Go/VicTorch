# 第三方依赖与许可证

码制、喷泉码、CRC、透视校正均为自行实现，运行时仅依赖 React。

| 名称 | 用途 | 许可证 | 免费商用 |
| --- | --- | --- | --- |
| react / react-dom | UI（运行时） | MIT | 允许 |
| vite | 构建（开发依赖） | MIT | 允许 |
| @vitejs/plugin-react | 构建（开发依赖） | MIT | 允许 |
| typescript | 类型检查（开发依赖） | Apache-2.0 | 允许 |
| vitest | 测试（开发依赖） | MIT | 允许 |
| @types/react, @types/react-dom | 类型声明（开发依赖） | MIT | 允许 |

新增任何依赖前必须先核对许可证并更新本表。
